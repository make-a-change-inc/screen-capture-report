# GOAL: 管理機能 Phase 2を本番実装する

## Objective

Phase 1の安全な認証・テナント基盤を維持し、元仕様で未実装のうち外部サービスなしで完結できる、レポート履歴とレビュー、AI化候補の判断管理、分類ルール、同意・データ申請を実装してCloudflare本番へ反映する。

## Deliverables

1. 暗号化されたレポート版履歴と、版ごとの完全性ハッシュ・生成日時・受信日時。
2. レビュー待ち・確定・配信済み・失敗の明示的な状態遷移と監査履歴。
3. AI化候補のレビュー状態、担当者、次のアクション、判断理由の永続化。
4. テナント別分類表示名・自動化率・有効状態の管理と、試算への即時反映。
5. 同意イベント、データ出力・削除申請、解決状態の記録と監査。
6. 全APIのCookie認証、CSRF、入力検証、テナント分離テスト。
7. PR、mainマージ、Cloudflareデプロイ、本番スモーク確認。

## Constraints

- レポート本文・秘密情報を監査メタデータへ保存しない。
- 過去版は上書きせず追加保存する。
- 状態遷移は許可表にない遷移を409で拒否する。
- 金額換算、メール配信、SSO/MFAを実装済みと見せない。
- 生画像・本人日報・詳細作業ログを管理サーバーへ追加送信しない。
