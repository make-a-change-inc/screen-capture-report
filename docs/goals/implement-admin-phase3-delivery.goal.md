# GOAL: レポートPDF出力と外部配信を実装する

## Objective

確定済み週次管理レポートをPDFとして保存でき、メール、Slack、Teamsへ手動またはスケジュール配信できる基盤を、外部接続状態と失敗履歴を偽らず管理できる形で実装する。

## Requirements

1. レポート詳細からブラウザの印刷機能を使ってPDF保存を開始し、出力操作を監査する。
2. メール宛先またはSlack／Teams Webhookを企業単位で設定し、宛先は暗号化保存して一覧にはマスク表示だけを返す。
3. 確定済みレポートだけを配信でき、配信要求、成功、失敗、プロバイダー参照、エラーコードを履歴として保存・監査する。
4. メールはCloudflare Email Service bindingと送信元が設定された場合だけ送信し、未接続時は503と失敗履歴を返す。
5. Slack／Teamsへはレポート本文や秘密情報を送らず、期間・対象名・管理画面リンクだけを送る。
6. 曜日、時刻、タイムゾーン、人による確定要否を設定し、確定不要のスケジュールだけを時間単位ジョブで自動配信する。
7. Ownerは接続・スケジュールを管理でき、Managerは確定レポートを手動配信でき、Auditorは更新できない。

## Acceptance

- UIとAPIでPDF監査、チャンネル設定、スケジュール、配信、履歴を扱える。
- Email Service未接続環境では成功を返さず、明確なエラーと失敗履歴を残す。
- Workerのテスト、チェック、ビルド、dry-runが成功し、本番で未認証401を維持する。
