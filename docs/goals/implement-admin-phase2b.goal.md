# GOAL: 端末運用品質と収集ポリシーを実データ化する

## Objective

Windows端末からプライバシー境界を越えない匿名運用集計を送信し、管理画面で取得率・分析成功率・停止理由・ポリシー適用状況を欠損と区別して確認できるようにする。

## Requirements

1. Bearer端末認証で日次heartbeatを受け付け、会社・端末・日付で冪等保存する。
2. 送信対象は件数、状態、アプリ版、適用ポリシー版だけとし、生画像、URL、ウィンドウタイトル、詳細作業ログを含めない。
3. Windowsアプリは既存のローカル運用指標からheartbeatを構成し、レポート同期と同じ同意・認証境界で送る。
4. 管理画面は取得率、分析成功率、失敗・欠損、停止理由を「未送信」と区別して表示する。
5. 利用目的、全体停止、除外アプリ・URLパターン・時間帯を版付きポリシーとして保存・監査し、端末取得APIを提供する。
6. テナント分離、入力上限、CSRF、秘密情報を含めない監査を自動テストする。

## Acceptance

- WorkerとWindowsの自動テストが通る。
- Cloudflare dry-runが通る。
- 本番で新しい画面と未認証401を確認できる。
