# GOAL: 分類訂正とプライバシー削除統制を実装する

## Objective

確定レポートの分類誤りを履歴付きで訂正・再集計できるようにし、データ削除申請を対象指定、リーガルホールド、削除証跡まで含む安全な運用フローにする。

## Requirements

1. 管理者は自社レポートのカテゴリ時間を別カテゴリへ移動でき、理由、実行者、日時を変更不能な訂正履歴として保存する。
2. ダッシュボード集計には適用済み訂正を決定的に反映し、レポートごとに再集計バージョンを表示する。
3. 削除申請は自社の従業員またはレポートを明示的に指定し、申請済みから処理中へ遷移した後だけ実削除できる。
4. 組織、従業員、レポート単位のリーガルホールド中は、手動削除と保持期限削除の両方を拒否する。
5. 実削除では関連するレポート、版、集計、端末運用メタデータを対象範囲内で削除し、対象IDのハッシュと件数を削除証跡として残す。
6. 全更新APIにCookieセッション、CSRF、テナント分離、入力検証、監査ログを適用し、監査ログへ本文や認証情報を保存しない。

## Acceptance

- Workerの自動テストで訂正後の再集計、リーガルホールドによる拒否、解除後の削除、削除証跡、テナント分離を確認できる。
- 管理画面で分類訂正、訂正履歴、対象指定削除、リーガルホールド、削除証跡を操作・確認できる。
- Cloudflare Workerのチェック、ビルド、dry-runが成功し、本番デプロイ後も未認証APIが401を返す。
