# GOAL: 複数管理者、RBAC、MFA、セッション管理を実装する

## Objective

企業ごとに複数の管理ユーザーを安全に運用し、役割に応じて閲覧・更新範囲を制限し、TOTP多要素認証とセッション失効を管理画面から扱えるようにする。

## Requirements

1. 初回の既存管理者ログイン時にOwnerをD1へ安全に移行し、以後は企業別管理ユーザーで認証する。
2. Owner、Manager、Auditorを実装し、Ownerは全権限、Managerは分析・レポート運用、Auditorは監査系の読み取り専用とする。
3. Ownerは管理ユーザーを追加し、役割・状態を変更し、対象ユーザーの全セッションを失効できる。最後の有効Ownerは降格・停止できない。
4. 各ユーザーはTOTPを登録・確認でき、有効化後はログイン時に6桁コードを必須とする。
5. MFA秘密鍵は一時登録と確認済み秘密鍵の両方を暗号化保存し、監査ログや画面再読込で再表示しない。
6. 権限拒否、MFA、ユーザー変更、セッション失効を自動テストし、全更新APIでCSRFとテナント分離を維持する。

## Acceptance

- Managerはレポート本文を閲覧・運用できるが組織設定を変更できず、Auditorは本文閲覧と全更新を拒否される。
- MFA有効化後はパスワードだけのログインが失敗し、正しいTOTP付きログインが成功する。
- Cloudflare Workerのテスト、チェック、ビルド、dry-runが成功し、本番で未認証401を維持する。
