# AI化トランスフォーメーション統合仕様

> Status: Grill-me approved  
> Date: 2026-07-22  
> Reviewer: GPT-5.6 SOL sub-agent

## 結論

- 添付HTMLをiframeや別ページにせず、既存管理画面の最上部へ再構成して統合する。
- 添付HTMLの独自トップバー、パンくず、外部Google Fontsは取り込まない。
- 表示データは添付HTMLの「10名・月間・169.3h → 35.0h・削減予想134.3h」に統一する。
- すべての数値をデモ用想定値として明示し、実測済み・本番連携済みと誤認させない。
- 個人名は標準表示せず、部署・業務単位で表示する。
- 上位3件を初期表示し、「10件すべて表示」で展開する。
- 週次レポートUIはOffにするが、受信API、D1、暗号化、冪等性、保持処理は維持する。

## 表示順

1. ページタイトル、対象期間・部署フィルター
2. AI化トランスフォーメーションの説明
3. 月間削減予想と算出母数
4. 業務 → 推奨AI → 導入後の10シナリオ
5. 算出根拠、想定値の注意事項
6. データ品質と運用上の要対応

## レポート機能Offの範囲

- サイドナビゲーションのレポート項目を表示しない。
- レポート出力、週次レポート確認ボタンを表示しない。
- 週次レポート3種とプレビューダイアログを表示しない。
- バックエンドの週次managementレポート受信APIと保存処理は変更しない。

## データ境界

- 管理画面には生画像、ウィンドウタイトル、個人ランキングを表示しない。
- 本画面の氏名・時間・削減率はすべてデモ用想定値とする。
- 本番データ接続時は、対象期間、対象人数、取得率、分析信頼度、算出式を必須とする。

## 受け入れ条件

- 「この作業を、このAIで、こう変える。」と「削減予想 134.3h / 月」が表示される。
- 10件の現状時間合計169.3h、導入後合計35.0h、差134.3hが一致する。
- 旧42名・週次・137.3hのデータが表示されない。
- 10件展開、詳細表示、Escで閉じる操作が動く。
- レポートナビ、レポートボタン、レポート一覧、レポートダイアログがDOMにない。
- 生画像と個人ランキングがない。
- 960px以下でシナリオがカード表示になる。
- 既存の管理API、端末API、暗号化、冪等性のテストが維持される。
